# Tech Stack - tourism.gov.ua

## Core Technologies
- **Language:** TypeScript (v5+) - Ensuring type safety and modern JS features across the full stack.
- **Framework:** Next.js 16 (App Router) - Providing high-performance server-side rendering and efficient routing.
- **Frontend Library:** React 19 - Leveraging the latest concurrent features and server components.
- **Styling:** Tailwind CSS 4 - Utility-first styling with modern performance optimizations.

## Backend & Content Management
- **CMS:** Payload CMS 3.x - A developer-first, headless CMS integrated directly into the Next.js application.
- **Database:** PostgreSQL - Robust relational data storage, managed via `@payloadcms/db-postgres`.

## Infrastructure & Environment
- **Containerization:** Docker & Docker Compose - Ensuring consistent development and deployment environments.
- **Asset Management:** Next.js Image component - For automated image optimization and delivery.
- **Slider/Media:** Swiper.js - For high-performance, touch-ready carousels and video sliders.

## Quality Assurance & Tools
- **Linting:** ESLint - Enforcing code quality and consistency.
- **Type Checking:** TypeScript - Static analysis for the entire codebase.
- **Testing:** Vitest & React Testing Library - For spec-driven development and unit testing of React components.
- **Accessibility:** Custom Accessibility Widget + Semantic HTML standards + ARIA compliant components.
